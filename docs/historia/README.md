## 📜 Regras de Ouro do Roteiro

- **Ambientação Real, Enredo Fictício:** O campus e os prédios da Unifor são reais e familiares para os estudantes locais, mas todas as pessoas, pesquisas médicas e eventos catastróficos são puramente fictícios.
- **Show, Don't (Just) Tell:** O jogador deve deduzir os séculos passados observando a erosão das paredes, as raízes profundas e os objetos desbotados antes de encontrar uma data ou confirmação formal.
- **Toda alteração de cânone** decidida pelo grupo deve ser imediatamente refletida em [`../decisoes.md`](../decisoes.md).
